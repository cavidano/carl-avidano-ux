I recently updated Natura11y to support contrast themes. Contrast themes allow users to replace a website’s colors with their own custom palette. People usually do this to enhance readability, but they may also set it for personal preference.

Windows <LinkOpenNew LinkUrl="https://support.microsoft.com/en-us/accessibility/windows/change-color-contrast-in-windows" LinkText="contrast themes" /> allow users to make this choice, and browsers implement it through a mode called <LinkOpenNew LinkUrl="https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/At-rules/@media/forced-colors" LinkText="forced colors" />. Microsoft previously reported that Windows High Contrast was enabled on 4% of Windows installations.

## Visible controls

In forced colors mode, browsers replace background colors with system colors and remove effects like box shadows. A button or panel that depends on a shadow or background fill can lose its visible boundary. Visible boundaries are important for usability. I added borders where those boundaries disappeared.

The keyboard focus outline needed to stay separate from the new borders. Natura11y already had a token to control the outline’s position, which made this easy to adjust. I moved the outline inward where needed, leaving a clear gap between it and the component’s border.

</TextBlock>

<TextBlock className="margin-x-auto">

## Clear states

I modified tab dividers and selected-state styles to keep the active tab recognizable. Selected pill-shaped tabs use the system’s highlight and text colors.

Dropdown and select arrows required careful attention because they are created with CSS borders. I left the side borders transparent. Then, I used system colors for the visible border. This included the disabled-text color for disabled selects.

</TextBlock>

<TextBlock className="margin-x-auto">

## Checking the work

I use <LinkOpenNew LinkUrl="https://polypane.app/docs/emulation/" LinkText="Polypane" />, a browser for developing and testing websites, to emulate forced colors. It allows me to check the same components in light and dark contrast themes side by side.

</TextBlock>

I also added automated checks against the Storybook examples in Chromium and Firefox.

These checks cover:

- Boundaries
- Selected states
- Arrows
- Switches
- Keyboard focus

They apply at different screen widths.

Emulation helps identify problems during development. The <LinkOpenNew LinkUrl="https://github.com/Natura11y/root/blob/main/packages/core/FORCED-COLORS.md" LinkText="review checklist" /> also includes checks using real Windows contrast themes in Edge and Firefox.

</TextBlock>

## Result

Core now includes these adjustments for both HTML and React components. The changes maintain useful visual cues while allowing the user to choose the color palette.

Natura11y needs to work when someone replaces its colors with a palette that makes their screen easier to read. Windows <LinkOpenNew LinkUrl="https://support.microsoft.com/en-us/accessibility/windows/change-color-contrast-in-windows" LinkText="contrast themes" /> let people make that choice, and browsers apply it through a mode called <LinkOpenNew LinkUrl="https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/At-rules/@media/forced-colors" LinkText="forced colors" />. Microsoft previously reported that Windows High Contrast was enabled on 4% of Windows installations. I wanted to preserve the cues that help people use an interface—where a control begins, which tab is selected, and what an arrow means—while respecting their chosen colors.

</TextBlock>

## Visible controls

In forced colors mode, browsers remove effects such as box shadows. A button or panel that relies on a shadow or background fill can lose its visible boundary.

I added borders where those boundaries disappeared, using the person’s system colors. Keyboard focus keeps its own outline, so it remains distinct from a component’s edge.

</TextBlock>

<TextBlock className="margin-x-auto">

## Clear states

I adjusted tab dividers and selected styles so the active tab stays recognizable. Pill-shaped tabs use the system’s highlight and text colors.

Dropdown and select arrows needed care because they are built with CSS borders. I kept the transparent sides transparent and used system colors for the visible part, including the disabled-text color for disabled selects.

</TextBlock>

<TextBlock className="margin-x-auto">

## Checking the work

I use <LinkOpenNew LinkUrl="https://polypane.app/docs/emulation/" LinkText="Polypane" />, a browser for developing and testing websites, to emulate forced colors. It lets me check the same components in light and dark contrast themes side by side.

I also added automated checks against the Storybook examples in Chromium and Firefox, covering boundaries, selected states, arrows, switches, and keyboard focus at different screen widths.

Emulation helps catch problems during development. The <LinkOpenNew LinkUrl="https://github.com/Natura11y/root/blob/main/packages/core/FORCED-COLORS.md" LinkText="review checklist" /> also calls for checks with real Windows contrast themes in Edge and Firefox.

Core now holds these adjustments for both HTML and React components. The changes preserve useful visual cues while leaving the color palette to the person using the site.

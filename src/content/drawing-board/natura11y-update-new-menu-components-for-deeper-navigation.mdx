<TextBlock className="margin-x-auto">

I added two navigation patterns to Natura11y for sites with multiple content levels: a flyout menu for moving between levels and nested navigation to group related pages. Both patterns draw inspiration from USWDS menu options, but I refined them—adding an out-of-the-box drill-down menu inside the flyout.

</TextBlock>

<TextBlock className="margin-x-auto">

## Flyout menu

The flyout opens a panel from the side of the screen. Choosing a section brings its links into view, with a back control to return to the previous level. Showing one level at a time gives a longer menu room to work on a small screen.

</TextBlock>

<FigureSingle width="medium" className="margin-x-auto" caption="The current Flyout example in Storybook, showing the first level of navigation.">

  <Image

<TextBlock className="margin-x-auto">

I reused Natura11y’s shared overlay behavior to keep keyboard focus inside the open menu and return it to the opening control when the menu closes. Inactive panels stay out of the tab order, so someone using a keyboard moves through the choices currently on screen.

Escape closes the menu. The transitions also respect the person’s reduced-motion setting.

</TextBlock>

<TextBlock className="margin-x-auto">

## Nested navigation

For someone already browsing a section, I added a sidebar that keeps its related pages visible. Indentation shows which pages sit beneath a parent, so the structure stays in view while someone chooses where to go next.

</TextBlock>

<FigureSingle width="medium" className="margin-x-auto" caption="The Nested Nav example in Storybook marks the American Robin section and Nesting as the current page.">

  <Image
    src={nestedNavExample}
    alt="Storybook showing Nested Nav and its HTML. American Robin has a vertical section bar, and Nesting is bold and underlined beneath it. Indented links show deeper levels within Eastern Bluebird."
  />

</FigureSingle>

<TextBlock className="margin-x-auto">

I used bold text and underlining to identify the current page, with a bar marking the active section. The markup also identifies the current page for assistive technology. Those cues connect a page to the section around it.

The component uses ordinary links in nested lists. People can Tab through the links and follow them with Enter, using the browser’s standard keyboard behavior.

</TextBlock>

<TextBlock className="margin-x-auto">

I recently added two navigation patterns to Natura11y to support deeper navigation:

- A flyout menu helps move between levels.
- Nested navigation groups related pages.

Both patterns were inspired by menu options in the U.S. Web Design System (USWDS). I added a ready-to-use drill-down menu inside the flyout.

</TextBlock>

<TextBlock className="margin-x-auto">

## Flyout menu

The flyout opens a panel from the side of the screen. Selecting a section reveals its links, with a back control to return to the previous level. Displaying one level at a time allows a longer menu to fit on a small screen.

</TextBlock>

<FigureSingle width="medium" className="margin-x-auto" caption="The current Flyout example in Storybook, showing the first level of navigation.">

  <Image
    src={flyoutExample}

</FigureSingle>

<TextBlock className="margin-x-auto">

I reused Natura11y’s shared overlay behavior to keep keyboard focus within the open menu and return it to the opening control when the menu closes. Natura11y excludes inactive panels from the tab order. Someone using a keyboard can navigate through the choices currently on screen.

Pressing Escape closes the menu. The transitions also respect the user’s reduced-motion setting.

</TextBlock>

<TextBlock className="margin-x-auto">

## Nested navigation

For users already browsing a section, I added a sidebar that keeps related pages visible. Indentation shows which pages are under a parent, so the structure remains clear while users choose where to go next.

</TextBlock>

<FigureSingle width="medium" className="margin-x-auto" caption="The Nested Nav example in Storybook marks the American Robin section and Nesting as the current page.">

  <Image
    src={nestedNavExample}
    alt="Storybook showing Nested Nav and its HTML. American Robin has a vertical section bar, and Nesting is bold and underlined beneath it. Indented links show deeper levels within Eastern Bluebird."
  />

</FigureSingle>

<TextBlock className="margin-x-auto">

I used bold text and underlining to highlight the current page, with a bar marking the active section. The markup also identifies the current page for assistive technology. These cues connect a page to the surrounding section.

The component uses standard links in nested lists. Users can Tab through the links and follow them with Enter, using the browser’s standard keyboard behavior.

</TextBlock>

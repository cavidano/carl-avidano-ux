Natura11y had grown across separate repositories for its core framework, React components, icons, and documentation. Keeping them aligned took more effort, and an update was long overdue.

As I brought more <LinkOpenNew LinkUrl="https://bradfrost.com/blog/post/ai-and-design-systems/" LinkText="AI-assisted development" /> into my work, I wanted the tools to have reliable context. That meant making the code and guidance easier to find and trust.

</TextBlock>

## One workspace

I moved Natura11y’s code and documentation into a <LinkOpenNew LinkUrl="https://github.com/Natura11y/root" LinkText="monorepo" />—one repository for related packages and applications. Now I could update a component, verify its examples, and revise its documentation in the same workspace.

I removed duplicate styles from the React setup so HTML and React components share Core’s styles. Storybook became the workbench for comparing their appearance and behavior.

</TextBlock>

<TextBlock className="margin-x-auto">

## Context for AI

After the move, I continued adding context in Figma. Component descriptions explain intended use and accessibility behavior. Backdrop guidance, for example, explains overlay and stacked layouts and makes clear that Core controls the responsive breakpoint.

</TextBlock>

<FigureSingle width="narrow" className="margin-x-auto" caption="Backdrop’s component description explains its layout behavior and which settings belong in production code.">

  <Image
    src={figmaContext}
    alt="Figma configuration for the Backdrop component, showing Overlay and Stack variants and guidance that Core controls the responsive breakpoint."
  />

<TextBlock className="margin-x-auto">

The Main Menu guidance separates Figma’s preview settings from the properties supported in React. That gives AI tools a clearer reference when translating a design into code.

I also connected Figma variables to Core’s CSS names and documented which source to follow when design and code disagree. Production code is the authority for accessibility and behavior.

</TextBlock>

<TextBlock className="margin-x-auto">

## Result

The code, examples, and design guidance now reinforce each other. I have clearer context to give AI tools and working components to check their output against. I’m still refining that guidance as I use it.

</TextBlock>

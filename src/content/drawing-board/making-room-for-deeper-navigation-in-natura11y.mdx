Badge followed as a smaller addition, giving labels and counts a consistent place beside other content.

## One level at a time

The flyout opens a panel over the page. Choosing a section brings its links into view, and a back control returns to the previous level. That gives a menu with several levels room to work on a small screen.

I reused Natura11y’s shared overlay behavior to keep keyboard focus inside the open menu and return it to the opening control when the menu closes. Inactive panels stay out of the tab order, so someone using a keyboard moves through the choices currently on screen.

Escape closes the menu. The transitions also respect the person’s reduced-motion setting.

</TextBlock>

<TextBlock className="margin-x-auto">

## Keeping the hierarchy visible

Nested navigation serves a different situation: someone is already inside a section and needs to see its related pages. It keeps those links together in a sidebar, with indentation showing which pages sit beneath a parent.

I used bold text and underlining to identify the current page, with a bar marking the active section. The markup also identifies the current page for assistive technology. Those cues connect a page to the section around it.

The structure uses ordinary links in nested lists, so it follows the browser’s standard keyboard navigation.

</TextBlock>

## Small labels in context

I added Badge for short labels and counts, such as an unread total beside an inbox link. It shares Natura11y’s typography and theme colors, with spacing that accommodates an icon when needed.

A badge can be a plain label, a link, or part of another control. I kept those uses in the underlying HTML: a label uses a span, while navigation uses a link.

The topic labels on this Drawing Board now use that same component. On article cards, the badge sits inside the card’s single link. On an article page, it links directly to the topic.

</TextBlock>

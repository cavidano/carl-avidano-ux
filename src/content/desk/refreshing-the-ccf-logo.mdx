The Cheetah Conservation Fund (CCF) needed a logo that worked at different sizes and in a single color. Its existing logo used a photograph of a running cheetah, which limited how the organization could use it.

## Keeping the familiar cheetah

Supporters already recognized the running cheetah, so I kept it at the center of the design.

I redrew the cheetah as a simpler vector image, which can change size without losing sharpness. I also updated the lettering. The refreshed logo kept the familiar cheetah while making it easier to use across web and print.

## Extending the identity across the website

The logo refresh was part of my work on Cheetah.org, which included navigation, layouts for different screen sizes, and publishing tools for CCF staff. I also designed the CCF Kids identity and created the custom Cheetah Tracks font, which CCF uses in email and print.

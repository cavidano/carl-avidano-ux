My work with Visionlearning spans branding, user experience, front-end development, and scientific illustration. The design system connects those parts of the project through reusable templates and interactive tools for a growing library of STEM resources.

## Starting with the learning experience

The platform serves students and educators in English and Spanish. That gave the front end a practical set of needs: responsive reading layouts, clear navigation, and room for tools that help people understand the material.

Glossary highlights let readers explore unfamiliar terms. Teachers can connect lessons to Next Generation Science Standards. The interactive Periodic Table gives students another way into the science.

## A foundation for the next feature

I developed the reusable front-end system alongside the website. It continues to support feature development, so the work extends beyond the original set of pages.

That is the part I want to explore here: how a design system takes shape around the content, people, and practical needs of a client project. Visionlearning offers a useful example because the reading experience and the interactive features have to work together.
